# Манифест сегментации TD-MindMarkers

В проекте используется уже подготовленная сегментация корпуса, а не произвольное автоматическое деление текста. Файлы `parts.csv` и, при наличии, `books.csv` считаются авторитетными входными данными анализа.

`start_sent` и `end_sent` задаются по индексации предложений после сегментации корпуса инструментом `razdel`. Если полный корпус `quiet_don.txt` хранится локально у пользователя, он должен соответствовать той же версии текста, под которую рассчитаны границы.

`build_parts.py` оставлен как вспомогательный инструмент для явного построения сегментации по заголовкам, но основной pipeline не перезаписывает существующие `parts.csv` / `books.csv` без отдельного флага `--auto-build-segmentation`.

Если `books.csv` отсутствует, анализ по книгам пропускается; анализ по частям остаётся рабочим и строится по `parts.csv`.
