# Описание программы TD-MindMarkers

## 1. Назначение

Программа `TD-MindMarkers` предназначена для автоматизированного извлечения и анализа маркеров мыслительной деятельности в тексте романа М. А. Шолохова «Тихий Дон». Основной объект анализа — контексты, связанные с Григорием Мелеховым, в которых выражены размышление, понимание, воспоминание, сомнение, решение, внутренняя речь и близкие когнитивные состояния.

Программа применяется как инструмент компьютерной филологии: она не заменяет литературоведческую интерпретацию, а создаёт проверяемую количественную и контекстную основу для анализа.

## 2. Входные данные

| Файл | Назначение |
|---|---|
| `data/corpus/quiet_don.txt` | полный локальный корпус романа |
| `data/corpus/quiet_don_SAMPLE.txt` | демонстрационный корпус для проверки запуска |
| `data/markers/s1_markers.csv` | исходный список однословных маркеров |
| `data/markers/alexandrova_extract.txt` | дополнительный словарный слой |
| `data/markers/phrases.csv` | фразовые маркеры, 686 строк |
| `data/markers/exclusions.csv` | шумовые исключения |
| `data/markers/microthemes.csv` | справочник канонических микротем |
| `data/segmentation/parts.csv` | проектная сегментация корпуса |
| `config.json` | конфигурация запуска |

## 3. Выходные данные

Программа формирует CSV/Parquet-таблицы, Excel-отчёты, графики PNG/SVG и metadata-файл. Главный массив анализа — `TD_HITS_TAGGED.csv`, где каждая строка соответствует одному найденному маркеру и содержит контекст, маркер, микротему, семейство фраз, тип связи с Григорием Мелеховым, речевую перспективу и признаки качества.

## 4. Основной алгоритм

1. Загрузка конфигурации.
2. Загрузка корпуса.
3. Выделение структурных заголовков в `HEADINGS.csv`.
4. Очистка аналитического текста от заголовков.
5. Сегментация текста на предложения.
6. Токенизация предложений.
7. Лемматизация токенов.
8. Формирование `MARKERS_MASTER` из словарей.
9. Поиск WORD-маркеров по леммам.
10. Поиск PHRASE-маркеров по лемматизированным шаблонам.
11. Устранение вложенных фраз через `prefer_longest`.
12. Отметка WORD-маркеров внутри PHRASE-маркеров.
13. Фильтрация шумовых употреблений.
14. Привязка контекста к Григорию Мелехову.
15. Классификация речевой перспективы.
16. Привязка к частям корпуса.
17. Расчёт статистики.
18. Создание витрины примеров.
19. Создание отчётов качества.
20. Построение графиков.
21. Сохранение `RUN_METADATA.json`.

## 5. Методические особенности

Словарь делится на три уровня:

- `CORE`: точные маркеры мыслительной деятельности.
- `EXTENDED`: расширенные когнитивные и фразеологические формулы.
- `EXPERIMENTAL`: спорные кандидаты, не входящие в основной расчёт профиля `DIPLOMA_STRICT`.

Для защиты от завышения частотности применяется два механизма:

- `phrase_overlap_mode = prefer_longest`: при вложенных фразах в основной результат попадает наиболее длинное совпадение.
- `count_overlapping_word_hits = false`: отдельное слово внутри найденной фразы не считается в основной статистике.

## 6. Ограничения

Программа использует правиловой анализ и не выполняет полноценный синтаксический или семантический разбор художественного текста. Речевая перспектива определяется эвристически. Поэтому спорные случаи сохраняются в `QUALITY_DASHBOARD.xlsx` и `MANUAL_VERIFICATION.xlsx` для ручной проверки.
