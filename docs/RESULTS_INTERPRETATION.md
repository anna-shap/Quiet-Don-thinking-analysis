# Интерпретация результатов TD-MindMarkers

## 1. Главный принцип

Результаты проекта следует читать как формальную корпусную карту маркеров мышления. Программа не заменяет филологический анализ, а готовит таблицы и графики для дальнейшей интерпретации.

## 2. Какие результаты считать основными

Для ВКР основными считаются результаты профиля `DIPLOMA_STRICT`:

- шумовые случаи исключены;
- WORD внутри PHRASE не раздувает статистику;
- используются уровни `CORE` и `EXTENDED`;
- `EXPERIMENTAL` не входит в основной расчёт;
- для связи с героем в главных выводах предпочтителен `STRICT`, то есть `MelekhovLink = YES`.

## 3. Как читать `STATS.xlsx`

| Лист | Интерпретация |
|---|---|
| `overview` | общие параметры анализа |
| `profile_settings` | какие фильтры применены |
| `coverage` | какие маркеры встретились в корпусе |
| `marker_strict` | маркеры в строгих контекстах героя |
| `microtheme_linked` | какие типы мышления связаны с героем |
| `perspective_strict` | кто выражает мышление героя |
| `perspective_microtheme` | какие микротемы характерны для разных перспектив |
| `part_microtheme` | распределение микротем по частям |
| `melekhov_profile` | когнитивный профиль героя |
| `analytical_indices` | формальные индексы по частям |
| `density_by_part` | когнитивная плотность по частям |
| `noise_report` | исключённые шумовые случаи |

## 4. Как читать речевую перспективу

`NARRATOR_ABOUT_HERO` показывает, что мышление героя вводит повествователь. Это обычно самый устойчивый и филологически надёжный слой.

`HERO_INNER_SPEECH` показывает внутреннюю речь героя: `мысленно`, `про себя`, внутреннее проговаривание.

`HERO_DIRECT_SPEECH` показывает прямую речь героя, если он сам произносит когнитивный маркер.

`OTHERS_TO_HERO` показывает случаи, где другие персонажи обращаются к герою и побуждают его думать, понять, решить, вспомнить.

`OTHERS_ABOUT_HERO` и `OTHERS_NEAR_HERO` требуют ручной проверки, потому что чужая речь в художественном тексте сложна для поверхностной атрибуции.

## 5. Как использовать графики

`plot_melekhov_cognitive_profile` подходит для общего вывода о когнитивном портрете героя.

`plot_perspective_microtheme_heatmap` показывает связь между речевой перспективой и типами мышления.

`plot_part_microtheme_heatmap` показывает, какие микротемы сильнее представлены в разных частях.

`plot_inner_speech_share_by_part` показывает, где внутренний план героя выражен сильнее.

`plot_external_pressure_by_part` показывает, где герой чаще оказывается объектом чужой когнитивной оценки или побуждения.

## 6. Готовые формулировки для ВКР

Автоматизированный анализ показал, что маркеры мыслительной деятельности в романе распределяются неравномерно и различаются по речевой перспективе. Это позволяет рассматривать мышление героя не только как набор отдельных глаголов, но как систему языковых средств: прямые глаголы размышления, фразовые конструкции понимания, формулы памяти, маркеры решения, сомнения и внутренней речи.

Наиболее надёжные количественные выводы строятся по строгой связи с Григорием Мелеховым. Расширенная связь `PROBABLE` используется как дополнительный материал и требует ручной верификации.

Фразовые маркеры повышают полноту анализа, поскольку в художественном тексте мыслительная деятельность часто выражается не одним словом, а конструкцией: `пришла мысль`, `стало ясно`, `не мог понять`, `мысленно проговорил`, `мысль не давала покоя`.
