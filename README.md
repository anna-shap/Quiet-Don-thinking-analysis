Python-проект для воспроизводимого корпусно-филологического анализа маркеров
мыслительной деятельности в романе М. А. Шолохова «Тихий Дон».

Проект не является нейросетевой системой и не заявляет полноценного
автоматического понимания художественного текста. Он реализует объяснимый
правиловой pipeline: корпус → очистка заголовков → предложения → токены → леммы
→ однословные и фразовые маркеры → фильтрация шума → привязка к Григорию
Мелехову → речевая перспектива → статистика → графики → витрина примеров →
контроль качества.

Состояние финальной версии
--------------------------

В текущей версии реализовано:

1.  `phrases.csv` содержит 686 фразовых маркеров мыслительной деятельности.

2.  В рабочем профиле `DIPLOMA_STRICT` в `MARKERS_MASTER` формируется 711
    маркеров, из них 681 фразовый.

3.  Фразы разделены на уровни `CORE`, `EXTENDED`, `EXPERIMENTAL`.

4.  Добавлены семейства фраз `phrase_family`, чтобы анализировать не только
    отдельные фразы, но и группы близких конструкций.

5.  Добавлен справочник `microthemes.csv`, нормализующий микротемы.

6.  Заголовки корпуса выделяются в `HEADINGS.csv` и не попадают в аналитические
    предложения.

7.  Вложенные фразы обрабатываются режимом `phrase_overlap_mode =
    prefer_longest`.

8.  WORD-маркер внутри PHRASE-маркера сохраняется для аудита, но не считается в
    основной статистике.

9.  Добавлены поля объяснимости: `MelekhovEvidence`, `PerspectiveEvidence`,
    `PerspectiveConfidence`, `SpeakerDetected`, `AddresseeDetected`.

10. Добавлены отчёты `STATS.xlsx`, `SHOWCASE.xlsx`,
    `PHRASE_QUALITY_REPORT.xlsx`, `QUALITY_DASHBOARD.xlsx`,
    `MANUAL_VERIFICATION.xlsx`.

11. Добавлен `RUN_METADATA.json` с относительными путями, хэшем корпуса, хэшем
    конфигурации и параметрами запуска.

12. Создаются графики PNG и SVG, включая матрицы, когнитивный профиль героя,
    когнитивную плотность, внутреннюю речь и внешнее когнитивное давление.

13. Тестовый прогон и `pytest` проходят.

пользователем:

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ text
data/corpus/quiet_don_SAMPLE.txt
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Сегментация
-----------

Проект использует существующий `data/segmentation/parts.csv` как авторитетную
проектную сегментацию. Pipeline не пересоздаёт `parts.csv` автоматически.
Автопостроение границ возможно только явно, но для дипломной логики
рекомендуется использовать проверенную сегментацию.

Если `books.csv` отсутствует, анализ по книгам пропускается или остаётся с `Book
= UNKNOWN`. Анализ по частям работает через `parts.csv`.

Установка
---------

Рекомендуется Python 3.10.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ bat
py -3.10 -m venv .venv
.\.venv\Scripts\activate.bat
python -m pip install -U pip "setuptools==70.2.0" wheel
python -m pip install -r requirements.txt
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Проверочный запуск на sample
----------------------------

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ bat
python -m tdmm.run_pipeline --config config.json --corpus data\corpus\quiet_don_SAMPLE.txt --out out_demo_sample --make-plots --max-sents 50 --clean-out
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Полный запуск
-------------

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ bat
python -m tdmm.validate_project --config config.json
python -m tdmm.run_pipeline --config config.json --out out_final --make-plots --clean-out
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Ключевые графики
----------------

-   `plot_melekhov_cognitive_profile` — когнитивный профиль Григория Мелехова.

-   `plot_part_microtheme_heatmap` — матрица «часть × микротема».

-   `plot_perspective_microtheme_heatmap` — матрица «речевая перспектива ×
    микротема».

-   `plot_core_extended_by_part` — динамика CORE/EXTENDED по частям.

-   `plot_inner_speech_share_by_part` — доля внутренней речи героя по частям.

-   `plot_external_pressure_by_part` — доля чужой речи о/к герою по частям.

-   `plot_cognitive_density_by_part` — когнитивная плотность по частям.

-   `plot_top_phrase_families` — топ семейств фразовых маркеров.
